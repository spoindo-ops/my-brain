# 📧 B2B 랜딩페이지/이메일용 CTA 카피 세트 5가지 (Copy Sets)
**(톤앤매너: 권위적, 심각함, 정량적, 긴급성)**

### 🟢 Set 1: [미세플라스틱/환경 규제] - 시장 접근성 위협 강조
*   **타깃:** ESG 및 환경 규제에 민감한 화장품 제조사.
*   **핵심 메시지:** '쓰레기'가 아닌 '위험'으로 간주되는 성분 컴플라이언스 관리의 필요성.

| 요소 | 카피 (Korean) | 목적/활용 위치 |
| :--- | :--- | :--- |
| **[문제 제기]** (Headline) | **Q. 당신의 제품, EU 시장에서 '쓰레기'가 될 위험에 노출되어 있진 않습니까?** | 랜딩페이지 최상단 / 이메일 본문 시작 |
| **[위협 증명]** (Body Copy) | 전 세계적으로 미세 플라스틱 규제가 강화되면서, 단순한 성분표로는 시장 접근이 불가능합니다. 단 한 번의 컴플라이언스 실패가 막대한 리콜 비용과 판매 금지(Market Blockage)를 초래할 수 있습니다. **(규제 위반 손실액 $1M~$5M)** | 본문 상세 설명 (연구원 데이터 활용) |
| **[해결책 제시]** (CTA Button) | **AI 기반 컴플라이언스 감사 요청: 미세 플라스틱 리스크 점수 진단 받기** | 버튼 텍스트. '감사'라는 단어로 전문성 강조. |

### 🟡 Set 2: [규제 변화 속도] - 내부 지식의 한계점 부각
*   **타깃:** 규모가 크지만 규제 대응팀이 부족한 중견 기업.
*   **핵심 메시지:** '경험'에 의존하는 리스크 관리는 더 이상 통하지 않음.

| 요소 | 카피 (Korean) | 목적/활용 위치 |
| :--- | :--- | :--- |
| **[문제 제기]** (Headline) | **멈춰야 할 시간: '우리 회사 방식'만으로는 글로벌 규제 변화를 따라잡을 수 없습니다.** | 이메일 제목 또는 랜딩페이지 시작부. |
| **[위협 증명]** (Body Copy) | 법률팀의 경험과 오랜 노하우도 이제는 한계에 도달했습니다. 무역 정책, 화장품 성분금지 목록 등은 매주 실시간으로 변화하며, '사후 대응' 구조로는 예측 불가능한 손실(Loss of Opportunity)을 감당할 수 없습니다. | 본문 상세 설명 (Writer 메모리 활용) |
| **[해결책 제시]** (CTA Button) | **규제 Gap 분석 보고서 받기: 놓치고 있는 규제 위협 지수 확인** | '보고서'와 '지수(Index)'라는 명확한 산출물 제공. |

### 🔴 Set 3: [공급망 투명성] - 원료의 출처 리스크 강조
*   **타깃:** 글로벌 공급망을 가진 복잡한 제품 구조를 가진 기업.
*   **핵심 메시지:** 최종 성분뿐 아니라, 그 근원까지 완벽히 증명해야 함.

| 요소 | 카피 (Korean) | 목적/활용 위치 |
| :--- | :--- | :--- |
| **[문제 제기]** (Headline) | **'어디서 왔는지'가 곧 '팔 수 있는지'를 결정합니다: 공급망의 투명성 리스크.** | 랜딩페이지 헤드라인. |
| **[위협 증명]** (Body Copy) | 한 가지 원료라도 데이터 추적이 불분명하면, 전체 제품 라인이 전면 리콜 사태에 직면할 수 있습니다. 이제는 단순 서류 제출이 아닌, 블록체인 수준의 '전 과정 컴플라이언스'가 필수입니다. | 본문 상세 설명 (Researcher 근거 활용) |
| **[해결책 제시]** (CTA Button) | **공급망 리스크 매핑 시뮬레이션 요청: 데이터 누락 지점 확인하기** | 구체적인 행동을 유도하는 '시뮬레이션' 강조. |

### 🔵 Set 4: [전략적 비용 관리] - 투자 대비 절감액(GOLD) 극대화
*   **타깃:** CFO 또는 재무 의사결정권자 (Cost-conscious Buyer).
*   **핵심 메시지:** 리스크 관리는 '비용'이 아니라, 성장을 위한 최고의 '투자'임.

| 요소 | 카피 (Korean) | 목적/활용 위치 |
| :--- | :--- | :--- |
| **[문제 제기]** (Headline) | **비용 절감이 아닌, '미래 성장 가능성 확보'에 투자해야 할 때입니다.** | 이메일 본문 초입. 감성을 건드림. |
| **[위협 증명]** (Body Copy) | 규제 준수를 비용으로만 인식하는 순간, 기업은 취약해집니다. 저희는 리스크를 '회피해야 할 손실(RED)'로 보는 대신, 제거했을 때 확보할 수 있는 '미래 이익(GOLD)'의 관점으로 접근합니다. | 논리 구조 전환 강조 (전체 브랜드 톤 반영) |
| **[해결책 제시]** (CTA Button) | **무료 리스크-이익 분석 워크숍 신청: 예상 절감액 $L_{mitigation}$ 산출하기** | '워크숍'과 '예상 금액'이라는 구체적 가치를 제시. |

### 🟣 Set 5: [최종 통합/긴급성] - 종합 진단 요청
*   **타깃:** 모든 종류의 리스크에 대해 포괄적인 검토가 필요한 최고 의사결정자 (CEO급).
*   **핵심 메시지:** 복잡한 고민을 한 번에, 가장 객관적 데이터로 해결해 드립니다.

| 요소 | 카피 (Korean) | 목적/활용 위치 |
| :--- | :--- | :--- |
| **[문제 제기]** (Headline) | **만약 지금, 당신의 비즈니스가 규제 리스크 70%에 노출되었다면?** | 매우 강력하고 충격적인 가정 제시. |
| **[위협 증명]** (Body Copy) | 복잡하게 얽힌 글로벌 무역 정책, 환경 이슈, 그리고 성분 문제는 개별적으로 접근할 수 없습니다. 오직 모든 요소를 통합하여 '정량화된 지표'로 한 번에 파악해야만, 비즈니스의 진짜 위험도를 알 수 있습니다. | 종합적 문제 인식 유도. |
| **[해결책 제시]** (CTA Button) | **최종 컴플라이언스 진단 요청: 15분 무료 리스크 컨설팅 예약하기** | 가장 낮은 장벽(15분)으로 최고 가치(전체 진단)를 약속. |
