# 📐 모듈형 애니메이션 기술 사양서 V4.0: 데이터 주권 상실 (Data Sovereignty Loss)
**버전:** 4.0
**적용 범위:** 모든 마스터 콘텐츠 및 Funnel 소재
**핵심 목표:** 재무적 손실을 넘어 '시스템의 통제력 상실'과 '데이터 불안정성'을 시각적으로 극대화한다.

## 🌐 공통 구현 가이드라인 (Global Implementation Guidelines)
1.  **색상 팔레트:** Deep Navy (`#0D1B2A`) - 배경/기준 | Royal Gold (`#FFC300`) - 확보된 자산/해결책 | Critical Red (`#CC0000`) - 위험 임계점.
2.  **애니메이션 트랜지션:** 모든 변화는 **선형적(Linear)**인 느낌을 지양하고, **비선형적 가속도 (Non-linear Acceleration)**를 사용하여 불안정성과 긴급성을 강조합니다.
3.  **데이터 바인딩 우선순위:** 애니메이션 로직은 항상 외부 API 엔드포인트(`qa_router.py`)에서 반환되는 JSON 데이터의 변화율($\Delta$ Value)에 종속되어야 합니다.

## 📈 컴포넌트 1: 시스템 붕괴 그래프 (The Collapse Graph)
**[목적]** 단순히 수치가 떨어지는 것이 아니라, '시스템 자체가 기능을 상실하는' 서사적 위협을 표현합니다.
**[기술 사양]** SVG Path Manipulation 및 카스케이드(Cascade) 애니메이션.

| 속성 | 세부 스펙 (Developer Guide) | 구현 로직 (Code Hint) |
| :--- | :--- | :--- |
| **형태** | 3D 파동 형태의 곡선 그래프. 시간 축이 흐를수록 곡선의 기울기가 급격하게 부정적(Negative Slope)으로 변해야 함. | `d` 속성을 가진 `<path>` 엘리먼트를 사용하며, `MotionPath` 애니메이션을 적용합니다. |
| **붕괴 트리거** | 특정 임계치($T_{collapse}$) 도달 시, 그래프의 라인이 끊어지는 것이 아니라, **'정보 손실(Information Decay)'** 효과를 일으키며 붉은 노이즈 패턴으로 변환됩니다. | `Path`가 사라지기 직전, 모든 픽셀에 미세한 **Glitch Effect (Noise/Static)** 오버레이를 적용하고, 불규칙적인 깜빡임(`Opacity: 0% \leftrightarrow 100%`)을 반복합니다. |
| **애니메이션** | 초기 단계는 부드러운 하강(Ease-Out)으로 시작하여, $T_{collapse}$ 지점부터는 **비선형적 급락 (Exponential Decay)** 곡선을 따릅니다. | `cubic-bezier()` 함수를 사용하여 가속도를 점진적으로 증가시키고, 붕괴 순간에 강제적인 'Jump' 대신 불안정한 떨림(Jitter)을 추가합니다. |
| **데이터 바인딩** | Y축 데이터가 임계치 $T_{collapse}$를 위반할 때마다 그래프의 색상이 Deep Navy $\rightarrow$ Royal Gold $\rightarrow$ Critical Red로 순차적으로 오버레이됩니다. | `Stroke-dasharray`와 `Strokecolor` 변경을 조합하여, 위험도가 증가하는 영역을 시각적으로 '도장'처럼 찍어내는 효과를 줍니다. |

## ⚠️ 컴포넌트 2: 임계점 위반 경고 게이지 (Threshold Breach Warning Gauge)
**[목적]** 단순 수치 확인이 아닌, *되돌릴 수 없는 위험 상태*에 진입했음을 선언적으로 보여줍니다.
**[기술 사양]** 계기판(Gauge) 형태의 SVG 아크와 전역 오버레이 효과 결합.

| 속성 | 세부 스펙 (Developer Guide) | 구현 로직 (Code Hint) |
| :--- | :--- | :--- |
| **표준 작동** | 게이지 바가 채워지는 과정은 기존처럼 `Ease-Out`을 유지합니다. | 아크(Arc)의 `stroke-dashoffset` 애니메이션 사용. |
| **임계점 감지 ($T_{breach}$)** | 측정된 지표가 사전에 정의된 임계점($X$ 값)에 도달하는 순간, 게이지 바는 Critical Red (`#CC0000`)로 즉시 전환되며, 다음 3가지 시퀀스가 강제 실행됩니다. | **1. 비주얼 충격:** 화면 전체를 찰나의 `Red Flash` (Opacity 0 $\rightarrow$ 1 $\rightarrow$ 0)로 커버합니다. <br>**2. 사운드 트리거:** 고주파 경고음(Sine Wave Burst)을 동기화합니다. <br>**3. 컴포넌트 변화:** 게이지 내부의 숫자 영역이 **'위험 상태 진입 (Danger Zone)'** 텍스트로 오버레이 됩니다. |
| **데이터 출처 시각화** | $T_{breach}$가 발생할 때, 게이지 바 주변에 흐릿하고 불안정한 `Data Corruption` 패턴을 배경으로 삽입합니다. 이는 이 수치가 '신뢰 불가능'하다는 무의식적 메시지를 전달합니다. | SVG `<filter>`를 활용하여 노이즈(Noise)와 글리치(Glitch) 효과를 게이지 전체에 적용하고, 임계점 도달 시 `Opacity`가 최고조로 올라오게 합니다. |

## 🌫️ 컴포넌트 3: 데이터 출처 불분명 시각화 (Ambiguous Data Source Overlay)
**[목적]** 정보의 신뢰도가 낮거나 통제권이 외부(국외, 제3자 등)에 놓여 있음을 표현합니다. 이는 '데이터 주권 상실'의 핵심 시각 요소입니다.
**[기술 사양]** 레이어드 아티팩트(Layered Artifacts) 및 마스킹 효과.

| 속성 | 세부 스펙 (Developer Guide) | 구현 로직 (Code Hint) |
| :--- | :--- | :--- |
| **기본 상태** | 배경 데이터 차트나 KPI 텍스트 위에, 규칙적이지 않은 간격으로 작은 사각형/점 패턴의 노이즈 레이어를 깔아둡니다. (미묘한 불안정감 유지). | 반투명(Low Opacity)하고 무작위로 배열된 SVG `<rect>` 또는 `dot` 요소를 사용합니다. |
| **불분명화 트리거** | '데이터 주권 상실'과 관련된 논리가 언급될 때, 노이즈 레이어가 점차 증폭되어 전체 화면을 덮기 시작합니다 (Opacity Increase). | 노이즈 패턴의 크기와 밀도(Density)가 증가하며, 배경에 가려지던 핵심 데이터(`Royal Gold`로 강조된 수치 등)를 부분적으로 **마스킹** 처리하여 '정보 왜곡' 느낌을 줍니다. |
| **시각적 표현 (The Glitch)** | 노이즈 패턴은 단순한 색상이 아니라, 마치 TV 신호가 끊기는 듯한 `Chromatic Aberration` 효과(R, G, B 채널 분리)를 가지며 깜빡입니다. | SVG `<filter>`의 `feDisplacementMap`을 활용하여 데이터를 미세하게 떨리게 합니다. 이 떨림은 주기적이지 않고 무작위성을 띠어야 전문적인 '시스템 오류'처럼 보입니다. |
| **강조 메시지** | 노이즈가 극대화되는 순간, 화면 중앙에 경고 문구("Source Unknown", "Control Lost")를 Deep Navy 배경 위에 Critical Red 또는 White/Red의 조합으로 임팩트 있게 배치합니다. | 텍스트 자체에 미세한 떨림(Jiggle) 애니메이션을 적용하여 안정감을 거부하게 만듭니다. |
